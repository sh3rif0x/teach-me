Absolutely bro 😎. If your goal is to become a **UI Designer using Figma**, don’t try to learn every Figma feature first. Learn **design fundamentals → Figma → real UI projects → design systems → portfolio**.

# 🎨 Figma + UI Designer Roadmap

### 🟢 LEVEL 1 — Design Fundamentals

**Time: 1–2 weeks**

Before Figma, learn the rules that make a design look good.

- 🎯 Visual hierarchy
    
- 📐 Spacing & alignment
    
- 🔤 Typography
    
    - Font families
        
    - Font sizes
        
    - Font weights
        
    - Line height
        
- 🎨 Color theory
    
    - Primary / secondary colors
        
    - Contrast
        
    - Backgrounds
        
- 📦 Layouts
    
    - Grid
        
    - Columns
        
    - Containers
        
- ⚖️ Balance & consistency
    
- 👁️ Visual hierarchy
    

**Practice:**  
Take websites you like and try to recreate their layouts.
